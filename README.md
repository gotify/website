# gotify/website [![Build](https://github.com/gotify/website/actions/workflows/main.yml/badge.svg)](https://github.com/gotify/website/actions/workflows/main.yml)

-> https://gotify.net

## Run locally

```bash
$ yarn install
$ yarn dev
```

The API docs at /api-docs are built with [sourcey](https://github.com/sourcey/sourcey) from the
`docs/spec.json` of each gotify/server release (`api-docs/`). To run them locally:

```bash
$ yarn dev:api-docs
```
